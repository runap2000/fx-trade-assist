FX TRADE ASSIST PWA

GitHub Pages用ホーム画面アプリです。GitHubリポジトリのSettings > PagesでDeploy from a branch、main、/(root)を選びSaveしてください。公開後のURLをAndroid Chromeで開き、メニュー > ホーム画面に追加を選びます。

USDJPYの価格・5分/15分/1時間足OHLC・米国/日本の重要経済指標をbiquote APIから取得します。API仕様 https://biquote.io/docs/ 。データの遅延・可用性は保証されず、LINE FXのレートと一致する保証もありません。
通知はアプリを開いている間のブラウザ通知です。バックグラウンド常時監視には別途サーバーとプッシュ通知設定が必要です。売買候補は参考情報であり、投資助言・利益保証・自動発注ではありません。
